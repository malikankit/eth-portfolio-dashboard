ETH Portfolio Dashboard

Standalone build — calls GoldRush (Covalent) directly from your browser, no backend.

API settings

Stored only in this browser's localStorage — never sent anywhere but api.covalenthq.com. Anyone with access to this browser/tab can read it, so don't use this file on a shared or public machine with a production key.

If requests fail with a CORS-flavored error but the "Test connection" button also fails outright (DevTools shows a bare 403 straight from Cloudflare, not a missing-header CORS message): that's Cloudflare's Bot Management flagging your network, not a code issue. VPN/proxy exit IPs get hit by this often. Try disconnecting your VPN or switching networks — confirmed to fix it in practice.

Review & verify

Eyeball the data below, correct anything that looks wrong, and add notes. Untick tokens that aren't relevant (spam/airdropped junk) — only selected tokens are carried into the confirmed entry; the recent-lookups cache above always keeps everything, unfiltered. Nothing here is saved until you click Confirm & save.

Price (USD) is GoldRush/Covalent's own quote_rate, not CoinGecko's. For the current date it's balances_v2's live quote; for a past date it's either historical_balances' quote at the block GoldRush resolved for that date, or (when that 501s) portfolio_v2's daily-snapshot close. Covalent doesn't expose an exact quote timestamp, and its aggregation/exchange sources differ from CoinGecko's — so a small mismatch, especially on volatile days, is expected rather than a bug. The raw response for every call (including whatever price fields GoldRush actually sent) is kept in the audit log below if you need to double check what was fetched.
